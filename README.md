# SDF Splat Studio

開発者向け: [Generator 実装ガイド](docs/generator-implementation.md) — ファイル構成、モジュールの役割、DSL解析、生成処理、Worker通信、内部データ形式、拡張方法。

「間引き設定」はヘッダー下の独立したパネルで開きます。パネル内の「閉じる」か、もう一度「間引き設定」を押すと閉じます。チェック・選択欄・スライダーの操作領域を広げています。macOS Safari でパネル表示・チェック切り替え・スライダーのドラッグを確認済みです。Vision Pro 実機での操作は未確認です。

ファイルビュアーのファイル名の下に「表示中 / 元データ」のスプラット数を表示します。LoD の設定やカメラ距離による選択数を約0.25秒ごとに更新します。画面外や透明なスプラットも含む表示用の選択数で、実際に画素へ寄与した数ではありません。点群表示では元データの点数を表示します。

ファイルビュアーの「間引き設定」では、LoD のオン・オフ、描画数の基準（端末に合わせた自動設定、または1万〜500万）、描画数の倍率（0.05〜2倍）を変更できます。描画数の目標は「基準 × 倍率」で、元の点数に対する割合ではありません。初期値はオン・自動・1倍です。設定は即座に反映され、視点を保持します。読み込み時に LoD データを作成し、オフへの切り替えと点群表示用に元データも保持するため、読み込み時間とメモリ使用量が増えます。点群表示中は設定を無効にし、元の点を表示します。

SDF（符号付き距離関数）の表面を Gaussian Splat に変換し、Spark.js 2.4.0 で確認する生成ツールです。生成したデータは Gaussian Splat PLY / SOG として保存できます。

配信用ファイルはすべて `html/` にまとめています。一般のWebサーバーへ公開する場合は、`html/` の中身をそのまま配置してください。ビルドは不要です。WebXRにはHTTPSが必要で、`.mjs` はJavaScriptのMIMEタイプで配信してください。ローカルサーバーも `html/` を公開ルートにするため、URLは `/viewer.html` などのままです。

`viewer.html?url=samples/mfd1.sog` のように `url` パラメーターを指定すると、起動時にそのファイルを読み込みます。相対パスは `viewer.html` の場所を基準に解決し、HTTP/HTTPSの絶対URLも利用できます（別ドメインの配信元ではCORS許可が必要）。URLにクエリーを含める場合はパラメーター全体をURLエンコードしてください。起動画面の「サンプルを開く」からも開けます。

```sh
npm start
```

ジェネレーター（`/generator.html`）とファイルビュアー（`/viewer.html`）は、それぞれ独立したページです。トップページはジェネレーターへ移動します。各ページのURLから直接開いてください。両方の作業を保持したい場合は、別々のタブで開いてください。ファイルビュアーは PLY / SPLAT / KSPLAT / SPZ / SOG / ZIP / RAD に対応しています。生成した PLY は保存後にファイルビュアーで開けます。

各ページのヘッダーにある小さなアイコンで、全画面表示とヘッダー非表示を切り替えます。四隅のアイコンで全画面表示に入り、ヘッダーも隠します。ヘッダーのアイコンでは、通常画面のままヘッダーだけを隠せます。右上に残るアイコンで復元・終了でき、ボタンの説明はツールチップと読み上げラベルで確認できます。全画面APIに非対応のブラウザーでは、ヘッダー非表示による拡大表示を使います（ブラウザーのアドレスバーは残ります）。

このフォルダで起動すると、HTTPS（[https://localhost:8443](https://localhost:8443)）とHTTP（[http://localhost:8080](http://localhost:8080)）を同時に配信します。どちらからも通常表示を利用でき、Vision ProなどLAN接続でのWebXRにはHTTPSを使用します。Python 3.9以降とOpenSSLが必要です。ビルドやpip/npmパッケージのインストールは不要で、`python3 server/server.py` で直接起動できます（npmコマンドにはNode.jsが必要です）。`node scripts/serve.mjs` もPython起動用の互換入口として使えます。WebGL 2 と CDN への接続が必要です。生成と保存はブラウザー内で行います。

Python標準ライブラリのHTTP/HTTPSサーバーを使用し、初回起動時に自己署名証明書を `.certs/` に自動生成します。localhost・ホスト名・検出したLAN IPを証明書に含め、有効期限やIPの変更時には再生成します。Vision Proからは起動時に表示される `https://<LAN IP>:8443/viewer.html` を開き、自己署名証明書の警告を確認して接続してください。クライアント証明書は要求しません。秘密鍵・`.git/` などの隠しファイルとディレクトリー一覧は配信しません。

```sh
# glbvなどで8443を使用中の場合
npm start -- --port 8444
# HTTP側のポートも変更する場合
npm start -- --port 8444 --http-port 8000
# 証明書にIPやホスト名を追加
npm start -- --san 192.168.1.10
# HTTPだけを起動する場合
npm run start:http
```

ファイルビュアーの「表示」で「平行法」「交差法」を選ぶと、左右に並べた裸眼立体視に切り替わります。平行法は左目用・右目用、交差法は右目用・左目用の順に表示します。上部の2つの白い点を重ねるように見て、「立体感」で視差を調整してください（0 で視差なし）。平行法で像を重ねにくい場合はウィンドウ幅を狭めます。回転の中心を視差ゼロの面とし、回転・ズーム・移動は左右共通です。点群表示にも対応し、表示切り替えで視点は保持します。「視点リセット」は現在の表示幅にモデル全体を合わせます。

WebXR対応環境では、ファイルを開いた後に「AR」「VR」で没入表示できます（HTTPSまたはlocalhostが必要）。`../glbv/` と同じく、最大辺を約1mに合わせて視点の前方に配置します。ARは背景を透過し、面が検出されるとリングを表示、タップでその面に配置します。面検出が使えない場合も前方に表示します。VRは片手のピンチ移動で回転、両手のピンチで拡縮できます。点群表示にも対応します。「XRを終了」またはヘッドセット側の終了操作で元の視点・倍率・裸眼立体視設定に戻ります。非対応環境ではAR/VRボタンを無効にし、理由をツールチップに表示します。

1. 初期表示はトーラスです。Scene DSL を編集して「スプラットを生成」を押します。「複数SDFと毛・房」プリセットに複数objectの例があります。単一SDFのJavaScriptモードは廃止しました。サンプリング・スプラット・照明・エフェクトの設定UIは、DSLで省略した項目のデフォルト値として使います。エフェクト設定は左ペイン下部にあります。
2. 形状が探索範囲の境界にかかる場合は「探索範囲 ±」を広げます。細い部分が消える場合は、探索範囲を絞るか分割数を上げます。
3. ドラッグで回転、スクロールでズーム、右ドラッグで移動します。再生成しても視点は維持されます。「視点リセット」で形状全体に合わせ、「中心点」で配置を点表示できます。
   描画に3秒以上かかった場合、または1フレーム500 ms以上の状態が3回続いた場合は、メッセージを表示してプレビューを停止します。再生成に成功すると描画を再開します。停止中も保存でき、タブ切り替えだけでは再開しません。
4. 上部の「保存名」にファイル名を入力し、「PLY を保存」または「SOG を保存」で現在の生成結果を書き出します。拡張子は自動で付き、空欄の場合はプリセットに応じた名前を使います。入力した保存名は再生成後も保持します。RGB は法線から求めた明暗を焼き付けた SH0 です。PLY は Y 軸上向き、SOG は通常の splat ビュアーの読み込み時に Y 軸上向きになる座標系で保存します。

SOG 保存は [SplatTransform](https://github.com/playcanvas/splat-transform) 3.10.3 と WebP の WebAssembly を CDN から読み込み、専用 Worker 内で非可逆圧縮します。データのサーバー送信はありません。この生成ツールの SH0 データでは WebGPU は不要です。準備中や生成中・変換中は SOG ボタンを無効にし、非対応環境やライブラリの読み込み失敗時にも無効のまま理由を表示します。失敗後はページの再読み込みで再試行できます。変換中もプレビュー操作と PLY 保存は利用できます。保存した SOG はファイルビュアーで開けます。

### GPTチャット（生成画面・ローカルサーバーのみ）

`../cad` のPython/Codex app-serverブリッジを流用し、Scene DSL専用の編集チャットを追加しています。[チャット用DSL仕様](chat-modeling-guide.md)を会話の基本指示に読み込み、現在のDSLとデフォルト設定を送信し、応答のDSLをエディターへ反映して再生成します。手動編集が入った場合は変更案を保留します。停止、新しい会話、変更を戻す、画像添付（PNG/JPEG/WebP、3枚・各2 MiBまで）、生成エラーの自動修正（最大2回）に対応します。会話はタブごとに分かれ、サーバーのメモリーにのみ保持します。JSON保存に会話は含みません。

`/chat/status` が利用でき、Codexプロセスへ接続できた場合だけチャットを表示します。未ログインならログインボタンを表示します。APIなしの静的ホスティング、通信失敗、Codex未導入時はチャット部分を隠し、生成・編集・保存はそのまま利用できます。チャット欄の表示・非表示は初回ロード時の接続確認でのみ決定します。その後の接続確認（手動・30秒ごと・ネットワーク復帰時）は接続状態と操作可否を更新し、欄の表示・非表示は変更しません。

Codex CLIの認証を使用します。認証情報はサーバー側だけに保持します。必要に応じて以下を設定してください。

- `GS_CODEX_BIN`: Codex CLIの実行ファイル（未指定ならPATHとCodex/ChatGPTアプリ内を検索）
- `GS_CODEX_HOME`: 認証・設定フォルダー（既定 `.build/codex-chat`）。CADと認証を共用する場合はCADと同じフォルダーを指定
- `GS_CODEX_MODEL`: 使用モデル（未指定ならCLIの既定）
- `GS_CHAT_LOG=1` または `--chat-log`: 指示・応答を標準出力に記録（画像はメタデータのみ）

```sh
# CADの既定認証フォルダーを共用してHTTPで起動する例
GS_CODEX_HOME="$PWD/../cad/.build/codex-chat" python3 server/server.py --http --port 8080
```

## ジェネレーターの編集・JSON保存

PCでは CAD と同じ3ペイン構成（左：デフォルト設定、中央：Sparkプレビュー、右：Scene DSLコード）です。狭い画面ではプレビューとエディタを上下に配置し、スマートフォンでは3ペインを縦に並べます。各ペインは独立してスクロールできます。

エディタは CodeMirror 6 を使い、行番号・DSL構文の色分け・補完・検索・Undo/Redoに対応します。Tab / Shift+Tabでインデント、Ctrl / ⌘ + Fで検索、Ctrl / ⌘ + Enterで生成できます。

左上の「JSON を保存」でDSL全文と画面の全デフォルト設定・保存名を1つのJSONに保存し、「JSON を開く」で復元します。読み込みでは現在のプレビューを保持し、「スプラットを生成」で読み込んだ内容を反映します。不正なJSONや設定値、未対応バージョンはエラーにし、編集内容は保持します。途中のDSLも保存でき、DSL自体の構文検証は生成時に行います。PLY / SOGの保存は生成済みの結果を書き出します。

JSON形式は `format: "sdf-splat-studio"`、`version: 1`、`source`（DSL文字列）、`defaults`（全デフォルト設定）、`name`（任意の保存名）です。`defaults` のキーは `extent`, `resolution`, `size`, `thickness`, `color`, `secondaryColor`, `secondaryRatio`, `seed`, `ambientIntensity`, `mainIntensity`, `mainAzimuth`, `mainElevation`, `fillIntensity`, `effect`, `density`, `hairLength`, `hairWidth`, `disorder`, `variation`, `clump`, `clumpSize`, `base`。エフェクト項目を含まない従来のversion 1 JSONは、エフェクト設定を初期値で補って読み込みます。JSONの `effect`・`hairLength`・`hairWidth` はDSLの `effect.type`・`effect.length`・`effect.width` に対応します。`secondaryRatio` は0〜1で、画面では0〜100%に変換します。角度は度単位、色は `#RRGGBB` です。

配信にはビルド済みの `html/source-editor.bundle.js` とライセンス表示を同梱しており、従来どおり `html/` の配置だけで利用できます。エディタを変更する場合のみ `npm ci`、`npm run build:editor` で再ビルドしてください。ソースは `editor/source-editor.mjs` です。

## Scene DSL

「テディベア」プリセットは、短い毛のある体・頭・耳・手足、クリーム色のパッチ、目・鼻・口、赤い蝶ネクタイを24個のobjectで構成するサンプルです。約15万splatを生成します。[JSONサンプル](html/samples/teddy-bear.json)を保存し、ジェネレーターの「JSON を開く」から読み込むこともできます。見た目を再現するため、サンプリング・配色・effect・照明はDSL内で指定しています。

樹木のプリセットは「樹木：広葉樹」と「樹木：針葉樹」の2種類です。広葉樹は枝分かれした幹と丸く広がる葉群、針葉樹は段状の樹冠と短い針葉を表現しています。[広葉樹のJSON](html/samples/broadleaf-tree.json)・[針葉樹のJSON](html/samples/conifer-tree.json)からも読み込めます。配色・葉のeffect・照明などはDSL内で調整できます。

[DSLの書き方](html/dsl.html)（配信時は `/dsl.html`）に構文・関数・設定項目の一覧があります。SDF は負が内部、0 が表面、正が外部です。

```text
version 1;

let radius = 0.65;

sdf ball(x, y, z) {
  return length([x, y, z]) - radius;
}

sdf ring(x, y, z) {
  return torus(x, y, z, 0.7, 0.2);
}

scene {
  defaults {
    splat { thickness = 0.15; }
  }

  object fuzzyBall {
    shape = ball;
    transform { position = [-0.9, 0, 0]; }
    splat { color = "#e9bc82"; }
    effect { type = fur; density = 700; length = 0.16; width = 0.012; }
  }

  object smoothRing {
    shape = ring;
    transform { position = [0.9, 0, 0]; rotation = [30, 0, 0]; scale = 0.8; }
    splat { color = "#71bbde"; }
  }
}
```

- SDF定義と生成するobjectを分離し、同じSDFを複数のobjectから参照できます。各objectを独立に生成して結合するため、重なりの内側の表面も残ります。形状を融合する場合はSDF内で `union` などを使い、1つのobjectとして生成します。
- 各設定は「画面のデフォルト値 → scene.defaults → object」で項目ごとに上書きします。`sampling`、`splat`、`effect`、`lighting` を defaults と object 内に記述できます。scene直下の `lighting` も指定でき、画面の照明を上書きします（defaults内のlightingがあればそちらを優先）。
- `transform` はobject内で指定します。ローカル座標で表面と毛・房を生成し、一様拡大・回転・移動した後の法線で照明を焼き付けます。rotationは度単位のEuler XYZ、scaleは正の数値です。探索範囲はtransform前のローカル座標です。
- `scene { seed = 123; ... }` で共通シード、object内の `seed = 456;` で個別シードを指定できます。個別シードを省略すると共通シードとobject名から決定するため、objectの追加や並べ替えで既存の乱数配置が変わりません。
- 数式は四則演算・比較・条件式・数学関数・SDF呼び出しを使えます。ベクトルは配列で表し、成分ごとの演算はスカラー式で記述します。汎用JavaScript、ループ、再帰、プロパティ参照は使えません。未知の設定や範囲外の値は行・列付きで表示します。
- 生成はWorker内で行い、object単位の進捗と境界到達を表示します。上限はscene全体で50万splat・30秒です。失敗・中止時は前回の結果を保持します。

`define 名前 { ... }` で splat や effect などの設定を共通化できます。トップレベルに定義し、`splat = 名前;` で参照、`splat 名前 { ... }` で参照した設定を項目ごとに上書きします。

```text
define coat { color = "#e4bf91"; secondaryRatio = 0; }
define shortFur { type = fur; density = 1000; length = 0.02; width = 0.004; }
define longFur shortFur { length = 0.05; }

sdf ball(x, y, z) { return sphere(x, y, z, 0.6); }
scene {
  object body {
    shape = ball;
    splat = coat;
    effect = shortFur;
  }
  object head {
    shape = ball;
    transform { position = [0, 0.9, 0]; scale = 0.7; }
    splat coat { color = "#edcfaa"; }
    effect = longFur;
  }
}
```

`define 派生名 元の名前 { ... }` で継承でき、入れ子の設定も項目ごとに上書きします。`sampling`、`lighting`、`transform` にも同じ参照構文を使えます。複数ブロックをまとめた定義は `defaults = 名前;` または `defaults 名前 { ... }` で使えます。定義順は自由で、値の式にはトップレベルの `let` 定数を使えます。define名は定数・SDFとは別の名前空間です。重複名・未定義参照・循環参照はエラーになります。設定名・値は参照先のブロックに合わせて検証します。既存のDSLとJSONはそのまま利用でき、versionは1のままです。

探索範囲は各軸とも `[-範囲, +範囲]` です。格子セルの辺で符号が変わる位置を補間し、その平均を SDF のゼロ面へ近づけます。差分で求めた法線に沿ってガウスの短軸を向けます。「面内の広がり」と「厚みの比率」は、それぞれセル幅に対する接平面内と法線方向の標準偏差です。サンプル間隔より細い形状や、符号変化を拾えない面は生成されないことがあります。

「ベース色」に加えて「補助色」を指定できます。「補助色の割合」は各 splat を補助色に置き換える確率です（0% はすべてベース色、100% はすべて補助色）。色は混合せずどちらかを選び、既存の明暗を適用します。毛・房を含む各 splat に適用され、PLY / SOG にも反映されます。同じ設定と乱数シードなら同じ配色を再現できます。設定後に「スプラットを生成」を押してください。

## 照明

環境光の強さ（0〜1）、メインライトの強さ（0〜2）と方位角・仰角を指定できます。方向は表面から光源を見る向きで、Y 軸が上、方位角 0° は +Z、90° は +X、仰角 90° は +Y です。従来の固定方向の補助光も強さ（0〜2）を調整できます。初期値は従来の照明にほぼ合わせています。

明るさは `min(1, 環境光 + メイン強度 × max(0, 法線と光源方向の内積) + 補助強度 × 補助光の寄与)` です。「スプラットを生成」で各 splat の色に焼き付き、PLY / SOG にも反映されます。環境光だけにする場合はメインと補助の強さを 0 にします。

## 表面エフェクト

各objectまたは `scene.defaults` 内の `effect { ... }` で指定します。未指定の項目は「左ペインのデフォルト設定 → scene.defaults → object」の順に項目ごとに継承します。下表はUIの初期値です。設定後に「スプラットを生成」を押すと反映されます。再生成しても視点は維持され、PLY / SOG にも個々の splat の大きさ・向き・色が反映されます。

| DSLパラメータ | 既定値 | 範囲・指定値 | 内容 |
|---|---|---|---|
| `type` | `none` | `none` / `fur` / `fluffy` | 下地のみ / 毛・起毛 / モコモコ。`fur` は1本につき3 splat、`fluffy` は1房につき1 splat。 |
| `density` | `700` | 0〜4000 | ローカル座標の表面積1あたりの、おおよその毛・房の数。splat数ではありません。 |
| `length` | `0.16` | 0.01〜0.6 | 毛・房の長さの基準値。SDFと同じローカル単位。 |
| `width` | `0.012` | 0.001〜0.15 | 太さの基準値（ガウスの標準偏差）。見える幅そのものではなく、`fur` は先端ほど細くなります。 |
| `disorder` | `0.35` | 0〜1 | 毛・房ごとのランダムな傾きの強さ。0でこの乱れを無効にします。 |
| `variation` | `0.4` | 0〜1 | 長さ・太さの個体差。長さは基準の `1 ± 0.8 × variation` 倍、太さは `1 ± 0.6 × variation` 倍。 |
| `clump` | `0.3` | 0〜1 | 近くの毛・房に共通の傾きを与える強さ。0で毛束による傾きを無効にします。 |
| `clumpSize` | `0.25` | 0.03〜1 | 毛束の空間パターンの大きさ。SDFと同じローカル単位。 |
| `base` | `true` | `true` / `false` | 下地の表面を残すか。`type = none;` では常に下地を生成します。 |

```text
// object内（scene.defaults内でも指定可能）:
effect {
  type = fur;
  density = 700;
  length = 0.16;
  width = 0.012;
  disorder = 0.35;
  variation = 0.4;
  clump = 0.3;
  clumpSize = 0.25;
  base = true;
}
```

`seed = 123;` は `effect` 内ではなくsceneまたはobject直下に指定します（0〜1000000の整数）。同じDSL・画面のデフォルト設定・シードなら同じ配置を再現します。object名や分割数を変えた場合は配置も変わります。毛束は連続した空間パターンによる傾きで、毛同士の物理シミュレーションではありません。

半径1の球や初期トーラスでの設定例（object内に記述）：

```text
// 短毛
effect { type = fur; density = 1000; length = 0.10; width = 0.006; disorder = 0.15; clump = 0.15; }

// 長めの毛
effect { type = fur; density = 700; length = 0.25; width = 0.012; disorder = 0.35; clump = 0.5; }

// ボア・モコモコ
effect { type = fluffy; density = 120; length = 0.16; width = 0.045; disorder = 0.35; clump = 0.3; }
```

長さ・太さ・毛束の大きさはtransform前の値です。`transform.scale` で下地と一緒に拡大し、毛・房の本数は変わりません。`density = 0;` では毛・房を生成せず、`fur` / `fluffy` でさらに `base = false;` にすると出力が空になりエラーになります。

密度はセルの法線から推定した面積で補正し、根元を接平面内でずらしてSDF表面へ再投影します。高曲率の場所や粗い分割では均一にならない場合があります。毛・房と下地を含めてscene全体で50万splatが上限です。Gaussianは端がぼけるため、毛先や輪郭も柔らかくなります。[HTMLのエフェクト詳細仕様](html/dsl.html#surface-effects)に生成数の見積もりと各設定の作用を記載しています。
